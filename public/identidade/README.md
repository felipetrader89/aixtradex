Copie aqui o arquivo `logo.png` (a logo gerada no ChatGPT) sempre que ele mudar em `MazyOS/identidade/logo.png`.

O componente `src/components/brand/Logo.tsx` detecta automaticamente se `public/identidade/logo.png` existe:
- Se existir, usa a imagem real.
- Se não existir, usa um wordmark de texto (mesmas cores) como placeholder.

Não precisa mexer em código — só copiar o arquivo pra essa pasta.
